# বাজার দর (BazarDor)

বাজার দর হলো একটি আধুনিক ও রেসপনসিভ ওয়েব অ্যাপ্লিকেশন যা ব্যবহারকারীদের দৈনন্দিন নিত্যপ্রয়োজনীয় পণ্যের বাজারদর সহজে দেখতে ও তুলনা করতে সাহায্য করে।

## ব্যবহৃত প্রযুক্তি (Technologies Used)
- Next.js (App Router)
- Tailwind CSS
- BetterAuth (Email/Password, Google & GitHub Auth)
- MongoDB
- React Fast Marquee & React Hot Toast

## প্রধান ৫টি বৈশিষ্ট্য (Key Features)
1. **লাইভ প্রাইস ট্র্যাকার:** স্ক্রিনের উপরে স্বয়ংক্রিয়ভাবে চলমান মারকিউ স্ট্রিপ যা পণ্যের দামের ওঠানামা দেখায়।
2. **দাম বাড়া ও কমার ট্রেন্ড:** প্রতিদিনের দাম সবচেয়ে বেশি বৃদ্ধি ও হ্রাস পাওয়া শীর্ষ ৬টি পণ্য আলাদা সেকশনে দেখানো হয়।
3. **ক্যাটাগরি ও সর্টিং:** চাল, ডাল, তেলসহ নানা ক্যাটাগরি ফিল্টার এবং বাংলা সংখ্যা নির্ভর কম/বেশি দাম সর্টিং সুবিধা।
4. **প্রটেক্টেড ডিটেইলস পেজ:** লগইন করা ব্যবহারকারীদের জন্য বিভিন্ন বাজারের সর্বনিম্ন, সর্বাধিক ও গড় দামের তুলনামূলক টেবিল।
5. **প্রোফাইল ও তথ্য আপডেট:** ব্যবহারকারীরা তাদের প্রোফাইল দেখতে এবং নাম পরিবর্তন করতে পারবেন।
